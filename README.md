# たんともMAP — 開発中デモ

たんたんともだちカードの加盟店と特典を、スマートフォンの地図から探すWebアプリの操作確認用デモです。

このリポジトリには、配信に必要な静的ビルドのみを保存しています。アプリのソースコードや社内資料は含みません。

## 確認時の注意

- 正式サービスではありません。掲載情報は確認中です。
- 店舗情報は2026年8月26日時点の公式一覧を基にした開発データです。最新の特典・利用条件は各店舗でご確認ください。
- 店舗写真は掲載準備中です。未承認の画像は配信しません。
- Googleの有料API、決済機能、アクセス解析は利用していません。
- 現在地の取得は利用者の操作と許可がある場合のみです。取得した位置はブラウザ内の一時的な表示に使用します。
- 地図は国土地理院の淡色地図をリアルタイム表示します。出典リンクを常時表示し、小縮尺で必要な追加出典も表示します。APIキーや課金APIは使用しません。
- 一部の店舗位置はOpenStreetMapを根拠としています。画面に出典を示し、対象の位置データをODbLの下で提供します。地図の背景の出典とは別です。
- 公開URLは認証付きではありません。URLを知る方はどなたでも閲覧できます。

## 今回の修正

- 全179店舗・拠点（福知山市74店舗）を検索対象にしています。公式加盟店掲載139行を展開したもので、2店舗の取り込み漏れを復元しました。新規加盟が増えたという意味ではありません。
- 当初ピンのなかった68件を調査し、23件の位置を補完しました。店舗・入居施設を確認できた11件と、番地の代表点を確認できた12件です。後者には「住所付近・入口未確認」と表示します。
- ピン対象は132件（福知山市54件）、未確定は47件（福知山市20件）。未確定店も検索・店舗カードに残し、推測でピンは置きません。対象支店・住所が不明な店舗では行き先リンクも保留します。
- 住所・位置の確認日は2026年10月7日ですが、特典の確認日は2026年8月26日から変更していません。既存109件の入口位置や、全店の営業・加盟継続状況を今回すべて再確認したものではありません。
- 全画面地図、浮いた検索バー、カテゴリ別のピン、小さな店舗カードに更新しました。特典・外部地図ボタンを先に表示し、電話・Web・写真・確認日は「詳細」で開きます。近接ピンは件数表示にまとめます。
- MapLibre GL JSで[国土地理院の淡色地図](https://maps.gsi.go.jp/development/ichiran.html#pale)を描画します。表示ズーム7〜18。航空写真・実験的ベクトルタイルは使用しません。Googleの地図・ロゴ・画像も使用していません。
- ソース側の74件のテスト、OG collector 6件 / 16 assertions、lint、型検証、通常・デモビルド、公開ファイル検証、公式一覧の整合性確認が成功しました。スマホ320px / 390px幅で地図・検索・詳細を確認しています。
- 店舗選択後のエリア切り替えで、地図の余白が二重に計算される問題を修正しました。
- MapLibreのworkerを含む6つのビルドファイルと、OSM由来の公開位置データJSONを配信します。描画エンジンの配信量は旧版より増えるため、低速回線・実機の性能検証は引き続き必要です。

## 静的ホスティングへの引継ぎ

配信対象は `docs/` の中身です。このリポジトリを使う場合、追加ビルドは不要です。リポジトリ全体を配信対象にしないでください。ビルド資産と位置データJSON以外の社内資料や画像候補は含みません。位置データのライセンスと出典は `docs/data/reviewed-osm-locations.json` に記載しています。

Cloudflareへの移行・設定はこの更新では行っていません。位置確認待ち店舗の座標確認、掲載情報の現況確認、実機iPhoneでのGPS・キーボード操作は別途必要です。
